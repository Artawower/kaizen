## Superkeys and leaders

These should stay application-owned. The shared catalog should not store or render them.

| Super key / leader  | Context                   | Observed files                                           | Notes                                                                 |
| ------------------- | ------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------- |
| `RALT + RSHIFT`     | Global macOS/skhd         | `skhdrc-*`, Karabiner CapsLock mapping                   | Candidate global prefix. CapsLock maps to Right Option + Right Shift. |
| `ALT + SHIFT`       | Linux/Niri global         | `niri/config.kdl.tmpl`, `xremap/config.yml.tmpl`         | Niri global prefix, close to skhd global role.                        |
| `SPACE`             | Helix/Zed Vim leader      | `helix/config.toml.tmpl`, `zed/private_keymap.json.tmpl` | Already app-native.                                                   |
| `cmd+opt`           | Cmux pane/workspace layer | `cmux/private_settings.json.tmpl`                        | App-native prefix.                                                    |
| Vi normal mode keys | Xonsh prompt              | `xonsh/keybindings_*.xsh`                                | App-native prompt navigation.                                         |
| Compact aliases     | Xonsh shell               | `xonsh/aliases.xsh`                                      | Shell can render `p p` as `pp`, `v s` as `vs`, etc.                   |

## Surface encodings

The same mnemonic can appear differently depending on the consumer. The catalog
stores the mnemonic path, not the literal keystrokes or shell text.

| Catalog entry           | Editor surface                      | Shell alias surface | Notes                                                                  |
| ----------------------- | ----------------------------------- | ------------------- | ---------------------------------------------------------------------- |
| `projects.pick = "p p"` | `SPACE p p`                         | `pp`                | User-reported `pp` already exists as a project picker shape.           |
| `vcs.status = "v s"`    | `SPACE v s` or app-owned equivalent | `vs`                | Alias command remains owned by Xonsh.                                  |
| `files.find = "f f"`    | `SPACE f f`                         | `ff`                | Shell may choose a fuzzy finder, editor may choose native file picker. |
