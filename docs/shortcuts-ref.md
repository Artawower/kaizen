## App Navigation

| Shortcut | Keys | Description |
|----------|------|-------------|
| `app.buffers.pick` | `ALT + b` | Pick app buffer |
| `app.pane.focus.down` | `CTRL + ALT + n` | Focus app pane/view down |
| `app.pane.focus.left` | `CTRL + ALT + h` | Focus app pane/view left |
| `app.pane.focus.right` | `CTRL + ALT + i` | Focus app pane/view right |
| `app.pane.focus.up` | `CTRL + ALT + e` | Focus app pane/view up |
| `app.pane.move.down` | `CTRL + ALT + SHIFT + n` | Move app pane/view down |
| `app.pane.move.left` | `CTRL + ALT + SHIFT + h` | Move app pane/view left |
| `app.pane.move.right` | `CTRL + ALT + SHIFT + i` | Move app pane/view right |
| `app.pane.move.up` | `CTRL + ALT + SHIFT + e` | Move app pane/view up |
| `app.projects.pick` | `ALT + p` | Pick app project |
| `app.tab.next` | `SUPER + SHIFT + i` | Next app tab/buffer |
| `app.tab.previous` | `SUPER + SHIFT + h` | Previous app tab/buffer |
| `app.tab.switch` | `SUPER + 1..9` | Switch app tab/buffer by number |
| `app.tabs.pick` | `ALT + t` | Pick app tab |
| `app.workspace.next` | `SUPER + SHIFT + n` | Next app workspace/session |
| `app.workspace.previous` | `SUPER + SHIFT + e` | Previous app workspace/session |
| `app.workspace.switch` | `SUPER + SHIFT + 1..9` | Switch app workspace/session by number |
| `app.workspaces.pick` | `ALT + w` | Pick app workspace |
