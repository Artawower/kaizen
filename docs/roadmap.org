* Planned

** apply: обработка конфликта существующего chezmoi
Если у пользователя уже есть chezmoi с другим remote:
- Определить текущий git remote chezmoi source dir
- Сравнить с =dotfiles.source= из конфига
- Если не совпадает → предложить: Cancel / Backup & reinit
- Backup = rename source dir в =<dir>.bak.<unix-timestamp>=

** setup: клонирование dotfiles и выбор источника фич
Расширить setup flow:
1. Запросить =dotfiles.source= URL (если не указан)
2. =chezmoi init <url>= → клонировать репо
3. Проверить наличие =<chezmoi-source>/kaizen/features/=
4. Если есть → предложить выбор источника фич: *default* (встроенные) или *repo* (из dotfiles)
5. Показать picker фич из выбранного источника

FeatureStore должен поддерживать два пути: встроенный и из dotfiles-репо (с приоритетом пользовательского).

** apply: chezmoi init если не init-нут
Если =dotfiles.source= указан и chezmoi ещё не init-нут → =chezmoi init <url>= перед записью данных.

** apply: mise trust + mise install после chezmoi apply
После =chezmoi apply= chezmoi обновил =mise.toml=.
Запустить =mise trust && mise install= если в плане есть mise tools.

** doctor: показывать mise outdated
Добавить секцию с выводом =mise outdated= в =kaizen doctor=.
