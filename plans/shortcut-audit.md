## Конфликты и дубли

- `dotfiles/dot_config/skhd/skhdrc-colemak`: `lcmd + ralt + rshift - t` appears twice with the same action.
- `dotfiles/dot_config/skhd/skhdrc-qwerty`: `ralt + rshift + lshift - t` appears twice with the same action.
- `dotfiles/dot_config/aerospace/aerospace.toml`: many workspace actions are duplicated on numeric and mnemonic keys (same action, different keys) for SOC/TRM/WEB/DEB/DEV/ENT/THR/STU/AI/PRD and their move-node counterparts.
- `dotfiles/dot_config/zed/private_keymap.json.tmpl`: `cmd-.` and `cmd-\` repeat in both Workspace and Editor contexts with the same action.
- `dotfiles/dot_config/xremap/config.yml.tmpl`: `Super-c/v/z`, `Alt-Left/Right`, `Super-a/c/v/z`, `Ctrl-j/k`, and related edits are reused across context-specific blocks.
- `dotfiles/dot_config/private_karabiner/karabiner.json`: multiple app-specific rules intentionally repeat the same ctrl+tab / shift+tab semantics across Telegram, Firefox, Zen, and Safari; one caps_lock alternative rule is present but disabled.
- `dotfiles/dot_config/skhd/skhdrc-qwerty`: the `RAlt+RShift+a` Alt-Tab line is active but structurally odd in the source.
