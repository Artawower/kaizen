# Kaizen

What is `Kaizen`? It is a [Japanese word](https://en.wikipedia.org/wiki/Kaizen) that I really like, because I find the philosophy behind it resonates closely with my mindset.

Throughout my life as a developer, I have tried many different tools, languages, and approaches. I truly enjoy learning and exploring new ideas and architectures from different applications. I would say I always strive for the perfect setup. I realize it is impossible to find a truly flawless one, especially given the fact that some tools can be great for certain tasks, but awful for others. However, I enjoy the journey itself—the process of continuous improvement.


So, what exactly is Kaizen? It is an opinionated tool for quickly switching between different approaches just to try them out.


# Main ideas
- `Kaizen` is a single binary that helps you configure your entire system in one place.
- Platform- and language-agnostic:
  I found that many people have different preferences, so `Kaizen` doesn't depend on any specific language—use whatever you like!
- All common configurations in one place:
  Usually, I have to define dozens of keybindings, themes, UI settings, and fonts for each app separately. To me, that makes no sense. With `Kaizen`, you get a single source of truth. Check the [example directory](./docs/example) for more details.
- AI-friendly:
  Nowadays, there is no reason to ignore AI. You can simply install a skill and ask an agent to explain `Kaizen`'s features or implement your own!


## What Kaizen is not:
- It is not a replacement for chezmoi!
- It is not a package manager.
- It is not a replacement for Nix!


# Common questions
## What is the difference between it and Nix?

It's very simple: Nix is better 🙂 If you are already a Nix user, there is no reason to switch to Kaizen, simply because Nix is more deterministic.
